# TradingOS Product Requirements

Working name: TradingOS. Tagline: Build. Test. Trade. Protect.

## Primary User Goals
- Connect Dhan first, with future broker support.
- Define a strategy once and run it in Backtest, Paper and Live.
- Build strategies without code using indicators, operators and condition trees.
- Support Indian options with actual option contracts.
- Receive TradingView webhooks without direct broker execution.
- Protect capital through risk profiles, daily limits, kill switch and audit logs.
- Auto-create journal entries and analytics from algo trades.

## Navigation
Dashboard, Strategy Lab, Trading, Risk, Journal, Analytics, Integrations, Settings and Admin.
